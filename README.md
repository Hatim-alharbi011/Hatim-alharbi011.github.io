# موقع السيرة الذاتية — حاتم المحمادي

## كيف أعدّل المحتوى؟
كل النصوص في ملف واحد: **`content.js`**.

1. افتح المستودع على github.com ثم افتح ملف `content.js`.
2. اضغط أيقونة القلم (Edit).
3. عدّل النص بين علامات التنصيص فقط.
4. اضغط **Commit changes**. يتحدث الموقع خلال دقيقة أو دقيقتين.

## إضافة شهادة جديدة
1. **موّه رقم الهوية والجوال قبل الرفع** — المستودع عام ويراه الجميع. ارفع الشهادة صورةً (JPG)، لا PDF.
2. ارفع الصورة إلى `assets/certs`.
3. في `content.js` أضف سطرًا في `certFiles` (المسار والفئة)، ثم أضف اسمها في `certs.items` بالقسمين العربي والإنجليزي **بنفس الترتيب**.

## إضافة صورة (لوحة جديدة أو شهادة)
1. افتح مجلد `assets/bi` (أو `assets/certs`) ← **Add file ← Upload files**.
2. اكتب مسار الصورة في `content.js`، مثل `"assets/bi/p6.jpg"`.

## تنبيهات
- لا ترفع ملفات فيها رقم الهوية أو أرقام الجوال أو بيانات داخلية لجهة العمل؛ كل ما في المستودع العام مرئي للجميع.
- إن تعطل الموقع بعد تعديل، فالسبب غالبًا فاصلة أو علامة تنصيص محذوفة. افتح تبويب **Actions** أو ارجع للنسخة السابقة من **History**.

## الملفات
- `index.html` هيكل الصفحة · `styles.css` التصميم · `app.js` التفاعل · `content.js` المحتوى
- النشر تلقائي: أي تعديل على الفرع main يظهر على الرابط خلال دقيقة أو دقيقتين
