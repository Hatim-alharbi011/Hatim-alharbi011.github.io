# موقع السيرة الذاتية — حاتم المحمادي

الرابط: https://hatim-alharbi011.github.io

## التعديل
كل التعديلات من **لوحة التحكم**: https://hatim-alharbi011.github.io/admin.html

- الدخول بمفتاح GitHub خاص بهذا المستودع (طريقة إنشائه داخل صفحة الدخول).
- بعد أي تعديل اضغط **«حفظ ونشر»**، فيظهر في الموقع خلال دقيقة إلى دقيقتين.
- **قبل رفع أي شهادة: موّه رقم الهوية والجوال** بأداة التمويه في نافذة الإضافة. المستودع والموقع عامّان.
- ملف السيرة (cv.html) يُبنى تلقائيًا من نفس المحتوى، فيبقى متطابقًا مع الموقع دائمًا.

## التراجع عن خطأ
كل حفظ يُسجَّل نسخةً في المستودع. للرجوع: افتح `content.js` على GitHub ← History ← اختر النسخة السابقة.
